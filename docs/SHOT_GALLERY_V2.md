# Shot Gallery V2 — one revealed shooting surface

V2 keeps the V1 scoring/phase kernel and archived replay, and versions generation,
input set and aggregation. There are six direct targets on one shuttered surface,
a pictogram cue for color/shape/combination or the necessary number rule, then a
fixed-tick reveal. No card panels, tutorial or filler text. Figures have simple
stands and deterministic shot-impact feedback; rendering never decides correctness.

Twelve interleaved trials use seeded unique-answer alternatives, including larger,
smaller and the unique even number. Wait/deadline pressure grows gently without
levels or world resets. `PICK_0`…`PICK_5` is protocol2. The unchanged V1 kernel
computes awards/penalties into total; score is published only at terminal so a
signed target cannot truncate the twelve-trial aggregate. Early/wrong/timeout
answers remain recorded; double responses during feedback are unavailable.

Registry2.0, shared loader/runtime/recorder, versioned server adapter and V1 archive
are reused. Client score/seed tampering is ignored/rejected. Golden:
seedgallery2-golden, score9090, tick3035,
sha256:16a3e0a0167187f1ebb527676a3b6d3a06d0fe23a063afadbadf4030f8af1b6c.

Original tension music uses the existing Web Audio lifecycle:144BPM, low-register
minor/dissonant ostinato, triangle voices and pulse bass. No sampled commercial
music/assets. Mute, delayed resume, restart and voice cleanup remain shared.
