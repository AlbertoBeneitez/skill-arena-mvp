# Licencias y límites del laboratorio

## Tower Building Game
Upstream: https://github.com/iamkun/tower_game  
Licencia declarada: MIT. El bootstrap conserva el repositorio y su archivo LICENSE.

## HexGL
Upstream: https://github.com/BKcore/HexGL  
Licencia declarada por el proyecto: salvo indicación específica de un archivo, código y recursos bajo MIT. Se conserva LICENSE.

## Agar.io clone
Upstream: https://github.com/owenashurst/agar.io-clone  
Licencia declarada: MIT. El nombre del juego original no se considera una marca de Skill Arena; este upstream se usa como laboratorio técnico.

## osu! lazer
Upstream: https://github.com/ppy/osu  
El proyecto declara MIT para código y framework, pero la marca osu!/ppy y los recursos del juego tienen condiciones separadas. Por eso SkillArena2 importa solo las áreas de código relevantes y no pretende redistribuir su identidad o recursos como un juego de Skill Arena.

## Política del experimento
"Prácticamente copiado" significa conservar el upstream y su lógica en el laboratorio cuando la licencia lo permite. No significa asumir que todas las marcas, nombres comerciales, canciones, gráficos o recursos de terceros quedan automáticamente cubiertos por la licencia del código.
